# 🏦 Bank Management System — C++

> End project for **Course 7: Algorithms & Problem-Solving – Level 3**

---

## 📌 About

A console-based bank management system built in C++.

The project is split into two modules that work together: a client management system with full CRUD operations, and a transactions menu for handling deposits, withdrawals, and balance views.

Built without OOP — entirely procedural using structs, functions, and file I/O, following clean code and Divide & Conquer principles from the roadmap.

---

## ✨ Features

### 👤 Client Management (CRUD)
| Operation | Description |
|---|---|
| ➕ Add Client | Register a new client with account number, name, phone, PIN, and balance |
| 🔍 Find Client | Search for a client by account number |
| ✏️ Update Client | Modify any client's information |
| 🗑️ Delete Client | Remove a client from the system |
| 📋 Show All Clients | Display all registered clients in a formatted table |

### 💰 Transactions
| Operation | Description |
|---|---|
| ⬆️ Deposit | Add funds to a client's account |
| ⬇️ Withdraw | Withdraw funds with balance validation |
| 📊 Total Balances | View balances of all clients across the system |

---

## 🛠️ Concepts Used

- Structs for client data modeling
- Functions & clean code (Divide and Conquer)
- File I/O for persistent data storage
- Input validation
- Loops and conditional logic
- Menu-driven console interface
